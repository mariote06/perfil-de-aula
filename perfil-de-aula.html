Configuração necessária

Para os alunos se ligarem pela internet, esta app precisa de uma base de dados Firebase gratuita (guarda apenas o PIN e o estado do treino em tempo real).

Abre o ficheiro index.html num editor, procura por firebaseConfig perto do fim do ficheiro, e cola a configuração do teu projeto Firebase (ver LEIA-ME.md incluído). Depois volta a publicar no GitHub Pages.
