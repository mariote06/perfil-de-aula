Configuração necessária

Para os alunos se ligarem pela internet, esta app precisa de uma base de dados Firebase gratuita (guarda apenas a aula, o estado do timer e os dados de pedalada durante a sessão).

Abre o ficheiro perfil-de-aula.html num editor, procura por firebaseConfig e cola a configuração do teu projeto Firebase (ver LEIA-ME.md). Faz o mesmo em aula-ao-vivo.html e volta a publicar no GitHub Pages.
